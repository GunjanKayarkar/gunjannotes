1.  For resizing the window, you can either enable Fractional Scaling from the display panel and set it to 125%, OR use Gnome Tweak Tools and increase the Scaling Factor of its Fonts to around 1.2 
2.  The Bluetooth problem arises because of using Pulseaudio drivers on Ubuntu. To fix it you may switch to Pipewire, so basically pickup the tutorial from the tutorials section and get your bluetooth back. In pipewire as well, you will have to select the msBC driver/settings for input and output for getting the AG audio that you use on Windows and Android. This msBC is similar to Handsfree AG where you can easily listen to calls from discord, gmeet and also play youtube without any issues. If anything goes wrong, like Ubuntu doesn’t recognize the sound drivers, just use the command to restart pipewire 
3.  Dash to Panel has its own Backup system like Nova Launcher, so just use it like nova launcher. 
4.  If you log into the various Online Accounts shown there in Ubuntu then the data from those accounts gets synchronized with various applications in Ubuntu. For example there is this Evolution called software that syncs your gmail email and calendar to your ubuntu calendar and so on. By default, Ubuntu also adds your google's account google drive as a network mounted drive, similar to how D drive and G drive are mounted.

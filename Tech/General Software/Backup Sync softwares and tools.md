1. Google drive
Except for the ocassional syncing issue where some file doesnt sync at all, this is kind of the best of the popular cloud services. Although there isnt any direct way to get google photos, but overall it gets the job done with selective folder sync and all. 

2. Onedrive
For keeping files from cloud to here and in sync its good, but doesnt have the feature like gdrive or syncthing where you can selectively sync an already present local folder to the cloud. You either have to move that folder to the dedicated onedrive folder on your system otherwise it wont sync. The selective local folder sync option is only available for a few pre decided folders like the documents folder, pictures folder etc etc. Also, in typical microsoft fashion, fucks over the default locations of documents, pictures etc and sets them inside onedrive without asking or just by default. Yikes.

3. Dropbox
Not much different than onedrive to be honest, has its pros over onedrive though, but there are also cons over that. It is same as of onedrive, doesnt sync external local folders, only the one inside main dropbox folder. But its backup feature can get your external drives backedup. Maybe they leverage this feature for local folder sync in the future, but even after that the backup feature uploads data to an entirely different dropbox site called dropbox/backup something which isnt accessible from the main dropbox homepage easily and on android toh there is no option to access that, walking duck.

4. Mega
Like google, does a great job at getting all the syncing as well as backups. Great job I would say, only is a bit more thodasa jyada intrusive than google hehe. There is no mount as separate drive option here like pcloud and gdrive though

5. pcloud
Same as mega and gdrive, gets stuff done. Only has mount as drive option unlike mega which gives only folder option while google gives both options. Also, the session expires everytime you close the app, so one complaint there

6. Syncthing
Perfect, just perfect. Also works over the internet as you did with Desktop Home PC and your mobile. Wonderful.

7. rclone
This+syncthing nothing can beat this combo just perfect!

8. Duplicati 2
Apparently, according to the internet, the backed up files with duplicati extension are not at all reliable. So best is to avoid this.
